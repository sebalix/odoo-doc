# Odoo 17.0 → 18.0

## Python Code

| Old | New |
|-----|-----|
| `fields.Serialized` | `fields.Json` |
| `tree_view_ref` (context key) | `list_view_ref` (context key) |
| `self.user_has_groups('group')` | `self.env.user.has_group('group')` |
| `check_access_rights()` | `check_access()` |
| `check_access_rule()` | `check_access()` |
| `_filter_access_rules()` | `_filtered_access()` |
| `_filter_access_rules_python()` | `_filtered_access()` |
| `_name_search` | `_search_display_name` |
| `_search(..., access_rights_uid=...)` | removed — use `self.with_user(...)` before calling `_search(domain, offset, limit, order)` |
| `_check_recursion()` | `_has_cycle()` |
| `from odoo import registry` | `from odoo.modules.registry import Registry` |
| `registry(db_name)` | `Registry(db_name)` |
| `_("text")` | `self.env._("text")` |
| `search` override (for modifying results) | `search_fetch` override (see 17.0) |
| `from odoo.tools import ustr` / `tools.ustr(` | remove (deprecated, use `str()`) |

**Notes:**
- `copy` and `copy_data` now work on multiple records
- Searches on non-stored related fields raise an exception instead of
  logging a warning

**Field attributes:**

| Old | New |
|-----|-----|
| `group_operator` | `aggregator` |

## XML Views

| Old | New |
|-----|-----|
| `<tree>` | `<list>` |
| `</tree>` | `</list>` |
| `attrs="{'invisible': [('field', '=', False)]}"` | `invisible="not field"` |
| `attrs="{'invisible': [('field', '=', [])]}"` | `invisible="not field"` |
| `attrs="{'invisible': [('field', '=', 0)]}"` | `invisible="field == 0"` |

**Kanban views:**

| Old | New |
|-----|-----|
| `kanban-box` | `card` |
| `kanban-tooltip` | (removed) |
| `oe_kanban_colorpicker` | `widget="kanban_color_picker"` |

**Chatter:**

| Old | New |
|-----|-----|
| `<div class="oe_chatter">` | `<chatter />` |

**Notes:**
- Common direct attributes: `invisible`, `readonly`, `required`
- View IDs containing `_tree` do NOT need to be changed (only the view arch syntax)
- Missing fields in `invisible`, `readonly`, `required`, `domain`, `context` are auto-added as invisible
- The tree → list conversion is automated by
  `odoo/upgrade_code/17.5-01-tree-to-list.py` (`odoo-bin upgrade-code`)

## JavaScript

| Old | New |
|-----|-----|
| `/** @odoo-module **/` | (removed - no longer needed) |
| `extra_trigger` in tours | extra independent step with `extra_trigger` as `trigger` |
| `test: true,` in JS tour definitions | removed |
