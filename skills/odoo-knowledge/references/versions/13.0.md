# Odoo 12.0 → 13.0

## Python Code

| Old | New |
|-----|-----|
| `@api.one` | remove decorator (method becomes single-record) |
| `@api.returns` | remove decorator (deprecated) |
| `@api.cr` | remove decorator (deprecated) |
| `@api.model_cr` | remove decorator (deprecated) |
| `@api.model_cr_context` | remove decorator (deprecated) |
| `.suspend_security()` | `.sudo()` |
| `track_visibility="..."` | `tracking=True` |
| `._find_partner_from_emails(` | `._mail_find_partner_from_emails(` |
| `._search_on_partner(` | `._mail_search_on_partner(` |
| `._search_on_user(` | `._mail_search_on_user(` |

## XML Views

| Old | New |
|-----|-----|
| `<act_window>` shortcut tag | `<record model="ir.actions.act_window">`; `src_model` → `<field name="binding_model_id" ref="..."/>` |
| `<report>` shortcut tag | `<record model="ir.actions.report">`; `string` → `name`, `name` → `report_name` |
| `<field name="view_type">...</field>` | remove (view_type no longer exists) |

## JavaScript

| Old | New |
|-----|-----|
| `tour.STEPS.SHOW_APPS_MENU_ITEM` | `tour.stepUtils.showAppsMenuItem()` |
| `tour.STEPS.TOGGLE_HOME_MENU` | `tour.stepUtils.toggleHomeMenu()` |
