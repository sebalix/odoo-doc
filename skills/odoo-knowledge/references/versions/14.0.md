# Odoo 13.0 → 14.0

## Python Code

| Old | New |
|-----|-----|
| `selection_add=[("foo", "Foo")]` | `selection_add=[("foo", "Foo")], ondelete={"foo": "set null"}` |
| `@api.depends` on `_compute_display_name` | override `name_get` with `@api.depends`, or override `name_search` |
| `_name_search` returns `(id, name)` tuples | `_name_search` returns ids only |
| `.with_context(force_company=...)` | `.with_company(...)` |
| Direct access to `ir.actions.*` | use `_for_xml_id()` |
| `Char` fields with `size=X` | remove `size` attribute |
| Record rules with `global` field assignment | remove `global` field assignment (now computed) |

## XML Views

| Old | New |
|-----|-----|
| `invisible="state=='draft'"` | `attrs="{'invisible': [('state', '=', 'draft')]}"` |
| `readonly="state=='draft'"` | `attrs="{'readonly': [('state', '=', 'draft')]}"` |
| `<button string="...">` in list views | `<button title="...">` (string now shown as text) |

## Security

| Old | New |
|-----|-----|
| No ACLs for transient models | add explicit security ACLs (and optionally record rules) |

## Module Metadata

| Old | New |
|-----|-----|
| Version `13.0.x.x.x` | bump to `14.0.1.0.0` |

## Other

- Chatter messages with subtypes now show subtype description on UI (no need to repeat text in body)
