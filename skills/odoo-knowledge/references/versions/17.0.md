# Odoo 16.0 → 17.0

## Python Code

| Old | New |
|-----|-----|
| `name_get` override | `_compute_display_name` override |
| `get_resource_path(...)` | `file_path(...)` |
| `def pre_init_hook(cr)` | `def pre_init_hook(env)` |
| `def post_init_hook(cr, registry)` | `def post_init_hook(env)` |
| `def uninstall_hook(cr, registry)` | `def uninstall_hook(env)` |
| `search(..., count=True)` | `search_count(domain)` — the `count` parameter is removed from `search()` and `_search()` |
| `_search()` returns a list of ids | `_search()` returns a `Query` object |
| `search()` + `fetch()` | `search_fetch(domain, field_names, ...)` (new, single round-trip) |
| `_name_search(name='', args=None, operator='ilike', limit=100, name_get_uid=None)` | `_name_search(name, domain=None, operator='ilike', limit=None, order=None)` |

**Notes:**
- New grouping API: `_read_group(domain, groupby, aggregates, having=(), offset=0, limit=None, order=None)` returns a list of tuples (groupby values + aggregate values) instead of dicts, and supports `having` domains on aggregates and `count_distinct`/`recordset` aggregate specs
- The legacy `read_group()` (dict output) still works in 17.0; it is only deprecated in 19.0 and removed in 20.0

## XML Views

| Old | New |
|-----|-----|
| `attrs="{'invisible': [...]}"` | `invisible="..."` |
| `attrs="{'required': [...]}"` | `required="..."` |
| `attrs="{'readonly': [...]}"` | `readonly="..."` |
| `states="..."` | `invisible="state != ..."` |
| `invisible="1"` (in tree, non-column) | `invisible="True"` |
| `invisible="1"` (column in tree) | `column_invisible="1"` |

**Notes:**
- Fields marked `readonly=True` on the model cannot be imported; prefer view-level readonly

**Settings views:**

| Old | New |
|-----|-----|
| `<div class="app_settings_block ...">` | `<app ...>` |
| `<div class="o_settings_container ...">` | `<block ...>` |
| `<div class="o_setting_box ...">` | `<setting ...>` |
| `<h2>Title</h2>` (in block) | `<block ... title="Title">` |

**Templates:**

| Old | New |
|-----|-----|
| `owl="1"` | (removed) |

**Global variables available in views:**

| Old | New |
|-----|-----|
| `active_id` | `id` |
| `active_model` | removed, model name to hardcode |
