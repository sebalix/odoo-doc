# Odoo 14.0 → 15.0

## Python Code

| Old | New |
|-----|-----|
| `@api.model_create_multi` (if exists) | (removed - now default) |
| `@api.ondelete` | `@api.ondelete(at_uninstall=True/False)` |
| `SavepointCase` in tests | `TransactionCase` |
| `Environment.manage()` context | (not needed) |
| `ir.model*` access | use `sudo` or existing methods |

## QWeb Templates

| Old | New |
|-----|-----|
| `t-raw` | `t-out` |
| `t-esc` | `t-out` |

## Assets

| Old | New |
|-----|-----|
| `"qweb": [...]` in manifest | `"assets": {"web.assets_qweb": [...]}` |
| assets in templates | assets in manifest `web.assets_backend` / `web.assets_frontend` |
| `.js` → `.esm.js` (for ES modules) | rename for ESLint compatibility |

## Mail Templates

| Old | New |
|-----|-----|
| `${...}` (Jinja syntax) | `{{...}}` (`inline_template`) or QWeb (body) |
