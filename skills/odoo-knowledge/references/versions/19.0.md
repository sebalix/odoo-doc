# Odoo 18.0 → 19.0

## Python Code

| Old | New |
|-----|-----|
| `self._cr` | `self.env.cr` |
| `self._uid` | `self.env.uid` |
| `self._context` | `self.env.context` |
| `from odoo import SUPERUSER_ID` | `from odoo.api import SUPERUSER_ID` |
| `odoo.osv.expression` | `odoo.fields.Domain` |
| `Domain([...])` (list) | `Domain(...)` (object) |
| `expression.AND(...)` / `expression.OR(...)` | `Domain.AND(...)` / `Domain.OR(...)`, or `&` / `|` / `~` operators between `Domain` objects |
| `expression.TRUE_LEAF` / `expression.FALSE_LEAF` | `Domain.TRUE` / `Domain.FALSE` |
| `SQL(...)` as a domain value | `Domain.custom(to_sql=lambda model, alias, query: SQL(...))` (optional `predicate=` callable) |
| `('partner_id', 'any', dom)` with `sudo()` to bypass record rules | `('partner_id', 'any!', dom)` — `any!` / `not any!` bypass record rules on the comodel |
| `Date.context_today(...)` / `relativedelta(...)` computed in Python | dynamic date values in domains: `'now'`, `'today'`, `'today +1d'`, `'today =1d'`, `'now =monday'` (auto-converted by `odoo/upgrade_code/18.5-00-domain-dynamic-dates.py`) |
| `auto_join=True` | `bypass_search_access=True` |
| `read_group` | `_read_group` (backend) or `formatted_read_group` (public) |
| `_read_group_raw` override | granular `_read_group_*` hooks (`_read_group_select`, `_read_group_groupby`, `_read_group_orderby`, `_read_group_postprocess_groupby`, `_read_group_postprocess_aggregate`, ...) |
| `_search(domain, offset, limit, order)` | `_search(..., *, active_test=True, bypass_access=False)` (new keyword-only parameters) |
| `toggle_active()` | `action_archive()` / `action_unarchive()` |
| `name_search(..., args=...)` | `name_search(..., domain=...)` |
| `@ormcache_context("key", ...)` | `@ormcache(self.env.context.get("key"), ...)` |
| `from urllib.parse import urljoin` | `from odoo.tools.urls import urljoin` |
| pytz / `self.env.context.get("tz")` | `self.env.tz` |
| `@api.returns` decorator | removed — adapt calls relying on its conversion behavior |
| renaming a method to `_name` to keep it out of RPC | `@api.private` decorator (keeps the public name) |

**Notes:**
- The ORM implementation moved to the `odoo/orm/` package; `odoo.api`,
  `odoo.fields` and `odoo.models` are now facade packages re-exporting it —
  public import paths are unchanged, do not import from `odoo.orm` directly
- `odoo.osv.expression` still works in 19.0 for compatibility; it is removed
  in 20.0
- `Domain` objects are immutable; plain lists and tuples are still accepted
  wherever a domain is expected
- `formatted_read_group()` is defined in the `web` module
  (`addons/web/models/models.py`), not in the core ORM
- When overriding `_search_*` methods of computed fields: the domain
  optimizer may rewrite the incoming operator/value (e.g.
  `search([("boolean_field", "=", True)])` arrives as `in` with
  `OrderedSet([True])`)

## XML Views

| Old | New |
|-----|-----|
| `<group expand="..." string="...">` in search views | remove `expand` and `string` attributes |

**Constraints/Indexes:**

| Old | New |
|-----|-----|
| `_sql_constraints = [...]` | `models.Constraint` / `models.Index` instances |

**Groups/Access:**

| Old | New |
|-----|-----|
| `res.groups.category_id` | `res.groups.privilege_id` (new model `res.groups.privilege`) |
| `groups_id` (on views, menus, actions, reports) | `group_ids` |

**Controllers:**

| Old | New |
|-----|-----|
| `@route(..., type="json")` | `@route(..., type="jsonrpc")` |

**Computed field search:**

| Old | New |
|-----|-----|
| return list/tuple | return `Domain` object |

**Tests:**

| Old | New |
|-----|-----|
| `odoo-test-helper` library | `from odoo.orm.model_classes import add_to_registry` |
| rely on demo data | create test data in tests (demo data not installed by default) |
